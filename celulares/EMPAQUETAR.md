# Herramienta de celulares por USB

Lo que se publica como `SinBuque-Celulares.zip` en `sinbuque.online`. Acá están sólo los
scripts propios; el resto del ZIP es **scrcpy 5.0** para Windows 64 bits, tal cual sale de
<https://github.com/Genymobile/scrcpy/releases> (Apache 2.0), y no se versiona.

Para armar el ZIP: extraer `scrcpy-win64-v5.0.zip` en una carpeta `SinBuque-Celulares/`,
copiar encima todo lo de esta carpeta menos este archivo, comprimir la carpeta y subirla a
`/opt/puente/server/deploy/descargas/` en el VPS.
